# output/

Generated by `python -m src.main`. Not committed (contains customer PII
carried over from the source tickets) -- see `DECISIONS.md`.

- `monthly_refunds.csv` -- tickets, refund amount, refund rate, and
  potentially-avoidable amount/rate per month.
- `refund_reasons.csv` -- ticket count, refund amount, % of total, and
  potentially-avoidable amount per *effective* reason code (i.e. after
  GW-OTHER tickets are reclassified from their free text).
- `agent_refunds.csv` -- per-agent ticket/refund counts, refund rate,
  potentially-avoidable amount, and GW-OTHER share, with a
  `low_volume_excluded_from_ranking` flag for agents with too few tickets
  to compare fairly.
- `flagged_cases.csv` -- individual tickets worth a human look: refund +
  replacement issued together, goodwill over the Rs 500 cap with no
  approval note, or an ambiguous classification.
- `executive_summary.md` -- the headline numbers in prose.
- `classification_cache.json` -- every GW-OTHER ticket's classification
  result, keyed by ticket_id. Re-running the pipeline reuses this cache
  instead of re-spending on tickets already classified.
