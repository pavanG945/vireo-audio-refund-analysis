# data/

Place the five files Vireo Audio provided here before running the tool:

- `tickets.csv`
- `orders.csv`
- `customers.csv`
- `products.csv`
- `agents.csv`

(`support-policy.pdf` is useful for context but not read by the code.)

These files are **not committed to this repository**. They contain
customer names, cities, phone numbers typed into free-text fields, and
other PII belonging to Vireo Audio's customers, and were shared with us
under a support-desk vendor evaluation, not for public redistribution.
See `DECISIONS.md` for the reasoning.

Expected filenames match `README.txt` from the original data pack; if you
received the files with random ID prefixes (e.g.
`9ac91960-...-tickets.csv`), rename them to the plain names above.
